# XAI for Beginners

A beginner-friendly frontend project that teaches Explainable AI.

Pages: Home, What is XAI?, AI Prediction, Explanation, Visualization, About Project.

## Run
Open `index.html` in any browser. No install or backend needed.

## Files
- index.html - page shell
- style.css - styles (light and dark mode)
- script.js - demo model, pages and charts

## Edit the model
In script.js, change the `F` array (features and weights) or `PRESETS` (sample students).
